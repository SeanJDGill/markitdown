Amazon invented one-click checkout, patented it, and built a habit so strong that
"buying" barely registers as a decision. Two decades later the flow is busier than it
once was — but the core principle hasn't changed: remove every step you possibly can.

## Defaults do the work

A returning customer already has an address, a card and a delivery preference. Amazon
treats those as defaults, not questions — so checkout becomes *confirming* rather than
*entering*.

<Insight number={1} title="Confirm, don't collect">
  For repeat purchases, the fastest form is no form. Show the saved values and let the user
  override only if needed.
</Insight>

## Make the risky step reversible

A one-tap purchase is only comfortable if mistakes are cheap. Amazon pairs aggressive
defaults with an easy, prominent cancel/return path — so speed never feels reckless.

  src="/placeholders/screen-b.svg"

## The takeaway

Amazon's checkout works because friction and risk are removed together: smart defaults to
go fast, and easy reversal so going fast never bites.
