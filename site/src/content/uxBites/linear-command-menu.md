Hit Cmd+K anywhere in Linear and a command palette appears with fuzzy search over every
action — create an issue, change status, switch teams. Nothing is buried more than a type
away, and the same surface teaches shortcuts by showing them next to each command.

**Steal this:** a command menu is the fastest navigation you can ship for a dense app, and
it doubles as a discoverability and accessibility win.
